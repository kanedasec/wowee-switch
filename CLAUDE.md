# Claude project entry point

Before changing this repository, read [AGENTS.md](AGENTS.md), then
[PROJECT_MEMORY.md](PROJECT_MEMORY.md), then the relevant portions of
[docs/FINDINGS.md](docs/FINDINGS.md).

`PROJECT_MEMORY.md` is the shared, tool-neutral handoff between Claude and
Codex. Update it in the same change whenever an operator-facing decision,
deployment fact, diagnosis, or implementation changes. Preserve the user's SD
card data: never delete or replace unrelated games, Nintendo data, or the WoW
`Data` tree.
